Cadence Virtuoso Studio & Siemens Calibre Integration

Adding Calibre to Cadence Virtuoso

End-to-end C-Shell (csh) tutorial for locating your Calibre installation, verifying shell variables, safely appending the Calibre SKILL interface (calibre.skl) to .cdsinit alongside existing EMX/PDK tools, and confirming startup in Virtuoso IC25.1.

01

Locate Calibre & Verify C-Shell Environment

env • find • which • ~/.cshrc

1A. Check Existing Environment & Locate Binary

Path Discovery
env | grep -iE "calibre|mgc|mentor|siemens"

Check if your lab administrator already configured CALIBRE_HOME, MGC_HOME, and PATH globally. If both variables appear (for example, CALIBRE_HOME=/cad/mentor/calibre/aok_cal_2026.1_35.25), you can skip ~/.cshrc edits and jump straight to Section 02.

ls -d /cad/* /opt/* /tools/* /eda/* 2>/dev/null | grep -iE "calibre|mgc|mentor|siemens"

Scan standard EDA server mount points for Calibre installation folders if environment variables are empty.

find / -name "calibre" -type f -executable 2>/dev/null

Search the filesystem directly for the calibre binary. The root folder immediately above /bin/calibre is your CALIBRE_HOME.

which calibre

Confirm which calibre executable resolves first in your active C-Shell PATH.

calibre -version

Verify the installed release version (use Calibre 2024.3 or newer—such as 2026.1—for clean menu integration with Virtuoso IC25.1).

1B. Manual C-Shell Configuration (~/.cshrc)

Only If Variables Are Missing
Add Calibre Root & License Server to ~/.cshrc csh / tcsh 
# Calibre Environment Setup (replace path with your root directory from Step 1A)
setenv CALIBRE_HOME /cad/mentor/calibre/aok_cal_2026.1_35.25
setenv MGC_HOME $CALIBRE_HOME
set path = ($CALIBRE_HOME/bin $path)

# License Server (uncomment only if not already set in a shared lab script)
# setenv SALT_LICENSE_SERVER 1717@your_license_server
# setenv MGLS_LICENSE_FILE 1717@your_license_server
After saving ~/.cshrc, reload your shell with source ~/.cshrc before launching Virtuoso.
02

Inspect & Back Up Cadence Startup File (.cdsinit)

ls -la • cat • cp • calibre.skl

2A. Audit Project Working Directory & Verify SKILL File

Pre-Flight Checks
ls -la .cdsinit ~/.cdsinit

Check both your project folder (e.g., myProjects/.cdsinit) and home directory (~/.cdsinit). Important: If a local .cdsinit exists in your launch folder, Virtuoso loads it and ignores ~/.cdsinit unless explicitly chained.

cat .cdsinit

Inspect existing tool configurations (such as Cadence EMX emxconfig.il and PDK stackup variables) so you append Calibre without overwriting existing setups.

cp .cdsinit .cdsinit.bak

Create a clean backup of your working .cdsinit file before appending new SKILL code.

ls -l $CALIBRE_HOME/shared/pkgs/icv/tools/queryskl/calibre.skl

Verify that the Calibre Virtuoso SKILL interface file exists and is readable at the standard queryskl path.

03

Link Calibre SKILL Interface to Virtuoso (C-Shell Safe)

.cdsinit • calibre.skl • csh echo

3A. Append Calibre Loader via Single-Line echo Commands

Recommended for csh / tcsh
echo "" >> .cdsinit echo '; Load Calibre Virtuoso Interface' >> .cdsinit echo 'let((s) s = strcat(getShellEnvVar("CALIBRE_HOME") "/shared/pkgs/icv/tools/queryskl/calibre.skl") when(isFile(s) load(s)))' >> .cdsinit

Why single-line echo? Interactive C-Shell (csh/tcsh) handles multi-line cat << 'EOF' pastes differently than Bash and often stalls at a ? prompt without writing to disk. Always use double >> (append) rather than single > (overwrite).

3B. Verified .cdsinit Structure & Editor Alternative

EMX + Calibre Coexistence
Resulting Project .cdsinit (EMX + Calibre) cat .cdsinit 
; Load Cadence EMX Virtuoso Interface
load("/cad/cadence/EMX/EMX_25.10.000/share/emx/virtuoso_ui/emxinterface/emxskill/emxconfig.il")

; Default gpdk045 Process Stackup File
EMX_process_name = "/home/samanM/RFIC_design/mPDK/gpdk045_v_6_0/vsrf/Model_Data/gpdk045_proc/gpdk045_nominal.proc"

; Load Calibre Virtuoso Interface
let((s) s = strcat(getShellEnvVar("CALIBRE_HOME") "/shared/pkgs/icv/tools/queryskl/calibre.skl") when(isFile(s) load(s)))
Confirm with cat .cdsinit that both EMX and Calibre entries are present.
Verbose SKILL Block (If Editing via vi / gedit) SKILL .cdsinit 
; Load Calibre Virtuoso Interface with Diagnostics
let( (calibreHome skillPath)
    calibreHome = getShellEnvVar("CALIBRE_HOME")
    if( calibreHome then
        skillPath = strcat(calibreHome "/shared/pkgs/icv/tools/queryskl/calibre.skl")
        if( isFile(skillPath) then
            load(skillPath)
        else
            printf("WARNING: Calibre SKILL file not found at %s\n" skillPath)
        )
    else
        printf("WARNING: CALIBRE_HOME is not set.\n")
    )
)
Prints explicit CIW diagnostics if CALIBRE_HOME or calibre.skl is ever moved.
04

Restart Virtuoso, Verify CIW & Access Calibre Menus

virtuoso & • CIW Log • nmDRC / nmLVS / PEX

4A. Launch Virtuoso & Confirm Startup Log

Verification & Usage
virtuoso &

Close any open Virtuoso session (File → Exit in the CIW), then relaunch from your project directory (myProjects) so the updated .cdsinit executes.

Layout / Schematic → Calibre

Open any Layout or Schematic cellview from the Library Manager. A Calibre menu now appears in the top menu bar with Run nmDRC, Run nmLVS, Run PEX, and Start RVE.
