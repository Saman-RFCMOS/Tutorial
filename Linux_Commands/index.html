Essential Linux & EDA Commands

01

Directory & File Navigation

cd • pwd • mkdir • ls

1A. Folder Navigation (cd & pwd)

Directory Traversal
cd <folder>

Go into a specific folder (for example, cd myProjects).

cd ..

Come out of the current folder (move up one parent directory).

cd ../..

Move up two directory levels at once.

cd ~ or cd

Return directly to your home directory.

cd -

Switch back to the previous working directory.

pwd

Print working directory (display full path of your current location).

1B. Creating & Listing Directories (mkdir & ls)

Folder Creation & Inspection
mkdir <dir_name>

Make a new directory in the current folder.

mkdir -p <dir1>/<dir2>

Create nested parent and child directories together in one command.

ls

List visible files and folders in the current directory.

ls -la

List all files (including hidden dotfiles like .cdsinit, .cshrc, .bashrc) with permissions, owner, size, and timestamp.

ls -lh

List files with human-readable sizes (KB, MB, GB).

ls -lt

List files sorted by most recently modified first.

02

Creating, Editing, Copying, Moving & Deleting Files

touch • gedit • nano • vi • cp • mv • rm

2A. Create, Edit & View Files

Editors & Log Inspection
touch <filename>

Create a new empty file (or update the modification timestamp of an existing file).

gedit <filename> &

Open file in the graphical text editor in the background (& keeps your terminal usable).

nano <filename>

Edit file in a beginner-friendly terminal editor (Ctrl+O to save, Ctrl+X to exit).

vi <filename>

Edit file in terminal (i to insert text, Esc then :wq to save & quit, :q! to quit without saving).

cat <filename>

Print the entire file contents directly in the terminal window.

head -n 30 <filename> / tail -f <filename>

View the first 30 lines, or follow a live simulation/solver log file in real time.

2B. Copy, Move, Rename & Delete

File & Directory Operations
cp <source_file> <dest_file>

Copy a file (for example, cp .cdsinit .cdsinit.bak).

cp -r <source_dir> <dest_dir>

Copy an entire directory and all of its subdirectories recursively.

mv <old_name> <new_name>

Move a file or folder to another path, or rename it in place.

rm <filename>

Delete a file permanently (use rm -i <filename> to prompt for confirmation).

rmdir <empty_dir>

Delete an empty directory safely.

rm -rf <dir_name>

Force-delete a directory and everything inside it recursively (always double-check the path before running).

find . -name "<pattern>"

Search recursively for files matching a pattern (for example, find . -name "*.proc" or find . -name "cds.lib").

03

Server Resources — CPU, RAM, Active Users & Running Time

uptime • w • top • free • lscpu • kill

3A. Active Users & Server Running Time

Server Load & Session Activity
uptime

Show current server time, total running time (uptime), number of logged-in users, and 1-, 5-, and 15-minute CPU load averages.

w

Display all active logged-in users, their login terminal, idle duration, and currently executing command or EDA tool.

who

List currently logged-in usernames, terminal sessions, and login start times.

last -n 10

Show the 10 most recent user logins and server reboot history.

3B. CPU, RAM, Disk & Process Monitoring

Hardware & Simulation Job Control
top

Live monitor of CPU %, RAM usage, and active jobs (P sorts by CPU, M sorts by RAM, q quits).

htop

Visual per-core CPU bars and memory usage monitor (if installed on the server).

free -h

Display total, used, and available system RAM and swap memory in human-readable GB / MB.

lscpu or nproc

Check server CPU architecture and total available processor cores for parallel EMX, Spectre, or ADS simulations.

df -h / du -sh *

Check overall server disk free space (df -h) and individual folder sizes in the current directory (du -sh *).

ps -u $USER / kill -9 <PID>

List your active processes and terminate a frozen job using its Process ID (<PID>).

04

EDA License Management (Cadence, ADS, HFSS, Calibre)

lmstat • setenv / export • lmgrd • lmreread

4A. Check Active Licenses & Server Status (lmstat)

FlexNet License Queries
lmutil lmstat -a -c <port>@<license-server>

Query the license server to view all active license daemons, total seats, and currently checked-out features.

lmutil lmstat -a | grep -iE "virtuoso|emx|ads|spectre"

Filter active license usage for specific Cadence, EMX, or Keysight ADS features and see which user holds each seat.

lmutil lmstat -c <port>@<license-server>

Quickly verify whether the FlexNet license server daemon is up and reachable from your machine.

env | grep -i LIC

Check which license server variables (CDS_LIC_FILE, LM_LICENSE_FILE, AGILEESOFD_LICENSE_FILE) are currently loaded in your shell.

4B. Change, Run & Manage Licenses (setenv / export / lmgrd)

Shell Configuration & Daemon Control
Change License in C-Shell ~/.cshrc
setenv CDS_LIC_FILE 5280@<license-server> Set Cadence Virtuoso, EMX & Spectre license server.
setenv AGILEESOFD_LICENSE_FILE 27000@<license-server> Set Keysight ADS license server.
setenv LM_LICENSE_FILE 27000@<license-server>:5280@<license-server> Set multi-tool FlexNet license search path (colon-separated).
Change License in Bash ~/.bashrc
export CDS_LIC_FILE=5280@<license-server> Set Cadence Virtuoso, EMX & Spectre license server.
export AGILEESOFD_LICENSE_FILE=27000@<license-server> Set Keysight ADS license server.
export LM_LICENSE_FILE=27000@<license-server>:5280@<license-server> Set multi-tool FlexNet license search path (colon-separated).
Apply Updated License Settings Reload Shell Config
source ~/.cshrc Reload C-Shell (csh / tcsh) configuration immediately without logging out.
source ~/.bashrc Reload Bash (bash) configuration immediately without logging out.
Run, Reread & Release License Daemon Admin & Recovery
lmgrd -c /path/to/license.dat -l /path/to/license.log Start the FlexNet license server daemon and write diagnostic output to a log file.
lmutil lmreread -c /path/to/license.dat Reload an updated license file without stopping active user sessions.
lmutil lmremove -c <port>@<license-server> <feature> <user> <host> <display> Reclaim a stuck license seat after an unexpected EDA tool crash (obtain <user>, <host>, and <display> from lmstat -a).
