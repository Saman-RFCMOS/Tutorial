HFSS Hotkeys & Tips

Ansys HFSS 3D Full-Wave EM

2A. HFSS Hotkeys

3D Modeler Selection & Navigation
f Face selection.
o Object selection.
e Edge selection.
b Select object/face behind current selection.
ctrl+d Fit all to screen.
center mouse click and move Rotate object.
left click and drag box to left Select all objects/faces/edges touching box.
left click and drag box to right Select all objects/faces/edges inside box.
X,Y,Z During move/copy operations, holding down X, Y or Z keys will restrict movement along those axes.

2B. HFSS Tips

Setup, Meshing & Automation Best Practices
01

In general use Driven Modal over Driven Terminal in Solution Type.

02

Set the right units before you start drawing.

03

HFSS Design Setting → Enable material override. This allows metals to overlap with dielectrics so it is very useful.

04

Set the right convergence parameters based on what you are interested in. S-parameters is default but not always optimal.

05

Global variables can be assigned by using a $ sign before the variable. This variable appears in all designs. For example $var_name.

06

Tools → Record Script to File and Run Script are very useful tools for automation.

07

Right-Click → Create Open Region is a fast way of making the radiation box.
